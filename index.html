lyanemacs

Emacs 設定、ACP agents 與 LSP 的安裝 / 同步腳本 GitHub

安裝

新電腦 / 初始化

purge apt Emacs、安裝 snap Emacs 31+，clone repo 到 ~/repos/lyanemacs 並 link / copy 設定檔。


  


  

    
同步最新設定

    
git pull 後更新複製的檔案；symlink 不需處理。

    

  


  

    
語言環境

    
不需 clone repo。python3 + pip + venv、nvm + Node.js LTS、rust (rustup)。不勾選：沒裝的逐一詢問 y/N；勾選：直接安裝 / 升級。

    

    

  


  

    
ACP agents

    
不需 clone repo。不勾選：沒裝的逐一詢問 y/N；勾選：直接安裝 / 升級。缺 Node.js 時會先詢問是否安裝。

    

    

  


  

    
LSP

    
不需 clone repo；python / web / php 裝在 ~/repos/lyanemacs 的 .venv、node_modules、vendor。

    

    

  


  
加 -y 可略過所有提問 (被取代的檔案仍會備份)；
    已有 checkout 時也可直接執行 ~/repos/lyanemacs/scripts/setup.sh <command>。
    lang / agent / lsp 也能單獨執行，例如 curl -fsSL …/scripts/agent.sh | bash -s -- claude。


  
檔案

  
依 manifest.tsv 安裝到家目錄；點檔名可直接檢視。

  

    
方式來源安裝到

    
      
scripts/setup.sh安裝 Emacs、同步設定；轉交 lang / agent / lsp

      
scripts/lang.shpython3、Node.js (nvm)、rust

      
scripts/agent.shACP agents

      
scripts/lsp.shLSP servers

      
scripts/common.sh共用函式 (各腳本自動載入)
